Open the counter

The counter runs on the Raspberry Pi at the station. This computer must be on the same network as the Pi.

Counter address
Open Part Counter

If it won't open: check the Pi is powered and on the network, then try its number address instead (for example 192.168.1.50:8080). Ask IT to reserve that address so it never changes.

Set up a new Pi, or update one

  1. Get the Pi ready. Raspberry Pi OS (64-bit) with SSH on, the camera connected, the official 27W power supply, and a network connection with internet.
  2. Log into the Pi from any computer (PowerShell on Windows, Terminal on Mac), using the Pi's username and name:
    ssh username@fatshark-camera1.local
  3. Paste this line on the Pi and press Enter. It installs the first time and updates every time after, keeping saved parts and the count log.
    …
  4. Open the counter with the button at the top of this page.

Already running? Inside the counter, open Detection and camera settings, then Software, and press Update now. No typing needed.
