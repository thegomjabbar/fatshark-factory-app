Station sign in / sign out

Select the station you're standing at, then scan a serial. The app checks whether that unit is already signed in here and automatically logs a sign-in or sign-out — same Log tab your existing tools already read. Signing a unit out of Station 6 marks it complete and shelf-ready for warehouse scan-out. Each scan is verified and written as one locked operation, so multiple computers scanning at once can't create conflicting entries. For speed, that check first looks at roughly the last week of activity — a unit stuck untouched longer than that still gets found correctly, just via one slightly slower search instead of an instant one.

For units that already have a serial recorded but never got a sticker printed (or it was lost/damaged). Paste the exact serial number(s) already assigned to those units. This does not check for duplicates, does not touch the dedupe library, and does not push anything to the sheet — it just reprints the label for serials that already exist. Ship to Warehouse maintenance tools

Bulk move out of Station 6

Paste a batch of serial numbers and this writes a proper "MoveOut · Station #6" row to the Log tab for any of them that aren't already checked out — skips anything already logged so nothing gets double-recorded. Useful for catching up a batch that physically left Station 6 without being logged one at a time.

Scrap serial numbers

For serials that were never used, or units being scrapped for any other reason. Writes a row to the Scrap Tracker tab, and permanently reserves each serial in this browser's dedupe library so it can never accidentally be generated again — same principle as "Undo last generate."

Reconcile shipped units stuck in an old station

Finds any serial that's already in SentToWH (meaning it physically left the building) but whose Log entry still shows it stuck at an earlier station (2/3/4/5) or missing entirely — usually leftover from an older process that didn't reliably close out the Log chain. Fixes the root data so it stops throwing off "stuck at station" counts and any downstream count of what still needs to be made. This does a full read of SentToWH and Log once, so it may take a moment on a very large sheet — that's expected for a one-time cleanup, unlike the fast per-box checks elsewhere.
